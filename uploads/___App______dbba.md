## 2. 产品概述与目标

### 2.1 一句话定位

**赛影**是面向摄影新手的 **VISION+ 手机摄影大赛学习助手**：把已公开的获奖结果与评委简介整理成可读档案，并用 AI 说明「评委可能偏好什么、这张作品为何可能入选」——**不是**图床、投稿工具或官方赛务后台。

### 2.2 背景

官网 VISION+ 提供作品集与 Photo Awards 页：

- 作品集可见 **2026、2025** 各约 **25** 件获奖作品、奖项类型、题材、机型、点赞/分享；详情多为弹窗，分享链形如 `/cn/works/detail?workId=`  
- 作品集页**无评委名单、无官方评语、无评委分数**；爱心为**点赞**，**不等于评分**  
- 评委信息在 Photo Awards，且需 **简体中文 / 中国区**；英文 Europe 视图可能隐藏评委区块  
- 2026 投稿截止公开信息为 **2026-06-26**（已结束）；页头可显示大赛状态，作品集内**无投稿按钮**

新手（Remi）难以从「结果列表」学到评委审美与可练习要点。

### 2.3 产品目标（v1）

1. 浏览并筛选 VISION+ **2025 / 2026** 获奖（及优秀，若入库）结构化结果  
2. 查阅评委库（仅本站公开简介 + 届次关联）  
3. **AI 评委风格分析**：页上简介 + 本届获奖题材/奖项分布 → 偏好摘要（标推断）  
4. **AI 入选原因解读（核心）**：单作「为何可能入选」+ 1～3 条练习建议；禁止伪造评语/分数  
5. 截图引用元数据、收藏与私人笔记  

### 2.4 设计原则

| 原则 | 要求 |
|------|------|
| 诚实性 | 区分「官网原文」与「推断」；likes ≠ jury score |
| 可追溯 | AI 输出绑定 `evidence_json` 公开字段 |
| 学习向 | 大白话；约 3 分钟读懂单作入选要点 |
| 克制采集 | 不默认下载原图做图床；不站外挖评委履历 |
| 边界清晰 | 不做投稿、不做 Film/Exhibitions 全库、不做其他赛事品牌 |

| 中文 | 英文参考 |
|------|----------|
| 年度最佳 | Best Photograph of the Year / Best of Year |
| 类别第一名 | Category 1st Place |

风光 Landscape · 人像 Portrait · 夜景 Night · 动态 Motion · 长焦与微距 Telephoto & Macro · 组图 PhotoSeries

### 3.4 评选机制（官网公开要点 · 作 AI 证据维度，非分数）

1. **组委会**资格筛查  
2. **初选**：构图、视角、创意、主题相关性等  
3. **专家评委**独立评分后汇总  
4. **蔡司专业风格奖**：蔡司相关评委**独立终审**路径（与主赛路径分开标注）

App 可将上述列为「可能被考量的公开维度」，**禁止生成虚构分值或假冒评语**。

### 3.5 Out of Scope（v1 明确不做）

见第 11 节完整表。摘要：2024 及更早；其他赛事品牌；评委站外履历/作品集；代投稿；批量图床；伪造评语分数；Film/Exhibitions 完整库；多赛事自动抓取；支付与社交 Feed。

## 4. 评委与 AI 分析核心（专章）

> 本章是产品差异化与工程实现的核心约束。所有风格标签均为**学习向推断**。

### 4.2 评委风格画像（推断 · 必须 UI 标注）

### 4.3 与本赛获奖结构的对照（推断，禁止写成「某人钦点」）

| 本赛事实 | 谨慎对应（推断） |
|----------|------------------|
| 2026 年度最佳《地球之巅》— CHUNLIN — 风光 — X300 Ultra | 更贴合 **风光 / 蔡司语汇**（可对照 Gola、Hönlinger 席位与蔡司奖路径） |
| 2025 年度最佳《太空战舰》— 歪杰 — 长焦微距 — X200 Pro | 更贴合 **微距创意 + 移动影像能力**（规则创意维度 + 于猛产品视角） |
| 人像类持续设奖 | 与肖全、黎晓亮（2026）、Hönlinger 肖像背景形成席位互补 |
| 蔡司专业风格奖 | 与 Gola、Hönlinger 蔡司身份及独立终审路径一致；解读单独标注 |
| 点赞数 | **不得**作为入选证据或评委分 |

### 4.4 核心能力定义

**基于本赛获奖图（题材 / 技法线索 / 奖项类别）+ Photo Awards 页上简介，推断「为何入选」。**

硬约束：

- 无官方评语、无评委分数可用  
- **likes ≠ scores**  
- 不得引用站外履历或站外作品集补强结论  

### 4.5 AI 输入 / 输出 / 证据 / 禁止项

#### 4.5.1 输入（允许）

| 输入类 | 字段示例 |
|--------|----------|
| 作品 | title, photographer, category, award_type, phone_model, description（若有）, year, work_id_ext |
| 评委 | name, role, bio_official（中文 Photo Awards 原文）, contest_ids |
| 届次聚合 | 该年题材分布、奖项分布统计 |
| 规则公开维度 | 构图 / 创意 / 主题契合；蔡司独立终审说明 |
| **禁止输入** | like_count 作为评分；站外网页；用户未授权的本地相册原图批量 |

#### 4.5.2 输出

| kind | 目标 | 内容要求 |
|------|------|----------|
| `style` | Judge 或 edition | 偏好题材、风格关键词、偏爱类型；分栏「原文」/「推断」 |
| `selection_reason` | Work | 「为何可能入选」3～6 要点 + 1～3 条练习建议；标明非官方评语 |
| `edition_overview` | Contest year | 可选：该届题材/奖项结构一句话概览 |

每条输出落库 `AnalysisResult`，含 `evidence_json`、`model_meta`、`created_at`。

#### 4.5.3 证据字段（`evidence_json` 建议结构）

```json
{
  "sources": [
    {"type": "work_field", "keys": ["title", "category", "award_type", "phone_model"]},
    {"type": "judge_bio", "judge_ids": [], "source_url": "…/photoawards"},
    {"type": "rule_dimension", "dims": ["composition", "creativity", "theme"]},
    {"type": "edition_distribution", "year": 2026}
  ],
  "disclaimer": "学习向推断，非官方评语或分数"
}
```

#### 4.5.4 禁止项（验收红线）

1. 伪造「评委原话」、打分、排名算法「官方结果」  
2. 将点赞表述为评分或入选依据  
3. 断言「由某评委一人钦点」某获奖作  
4. 使用评委站外赛事履历或站外作品集  
5. 对缺失字段编造（应显示「来源页暂无」）  

#### 4.5.5 AI 流水线（逻辑步骤）

1. **清洗**：Contest / Work / Award / Category / Judge.bio_official  
2. **标签聚合**：届次内题材、奖项、机型分布  
3. **风格摘要**（`style`）  
4. **入选原因 + 练习建议**（`selection_reason`）  
5. **落库**；前端只读；支持异步与失败重试

## 5. 功能需求（FR）

> 核心价值：**AI 分析评委为何选中这些作品**（学习向推断）。下列 FR 均需可测验收标准。

### FR-01 赛事与作品集浏览

- **描述**：按年份（2026 / 2025）、获奖/优秀、题材、奖项类型筛选列表；卡片与详情对齐官网公开字段。  
- **验收**：  
  - [ ] 可切换 2026 与 2025；默认可进入「获奖作品」  
  - [ ] 卡片至少含：标题、作者、题材、奖项（若有）、机型（若有）  
  - [ ] 点赞文案为「点赞」，不得显示为「评分」  
  - [ ] 可打开 `workId` 级外链或内嵌摘要  

### FR-02 获奖作品结构化归档

- **描述**：沉淀约各 25 件 2025/2026 获奖作及第 3.2 节奖项枚举；支持按奖项过滤。  
- **验收**：  
  - [ ] 2026 年度最佳可查：《地球之巅》— CHUNLIN — 风光 — X300 Ultra  
  - [ ] 2025 年度最佳可查：《太空战舰》— 歪杰 — 长焦与微距 — X200 Pro  
  - [ ] 过滤「年度最佳」时上述两条分别落在对应年份  
  - [ ] 奖项/题材枚举与第 3 节一致，不出现未定义类型  

### FR-03 评委资料库

- **描述**：展示第 4.1–4.2 节评委姓名、角色、Photo Awards **中文页**简介原文；关联届次。  
- **验收**：  
  - [ ] 2026 五人、2025 五人（含 Alex Webb）可列表与详情  
  - [ ] 简介可追溯 `source_url`；缺失显示「来源页暂无」  
  - [ ] v1 **无**「曾在其他赛事担任评委」类字段与 UI  

### FR-04 AI 评委风格分析

- **描述**：输入 = 简介原文 + 该评委所在届次获奖题材/奖项分布；输出偏好摘要。  
- **验收**：  
  - [ ] UI 严格区分「官网简介原文」与「推断」  
  - [ ] 推断文案不含站外履历  
  - [ ] 一位评委摘要可在约 1 屏内读完  
  - [ ] 蔡司相关评委可提示「蔡司专业风格奖另有蔡司评委终审路径」  

### FR-05 AI 入选原因解读（核心）

- **描述**：单件获奖作生成「入选要点」+ 练习建议；结合奖项、题材、说明、机型、本届评委席位对齐。  
- **验收**：  
  - [ ] 每件获奖作可打开一页入选卡片  
  - [ ] 标明非官方评语；likes ≠ score  
  - [ ] 可引用构图/创意/主题等公开维度，**无虚构分数**  
  - [ ] Remi 约 **3 分钟**可读懂单作要点  
  - [ ] 蔡司奖作品单独标注路径说明（若适用）  

### FR-06 截图引用（ScreenshotRef）

- **描述**：为作品/评委页保存截图引用**元数据**（本地路径或用户授权文件）；默认不镜像全站原图。  
- **验收**：  
  - [ ] 未授权不批量下载原图做图床  
  - [ ] 记录含 source_url、时间、关联 Work/Judge id  

### FR-07 收藏与笔记

- **描述**：收藏作品或评委；撰写私人笔记（练习计划、构图观察等）。  
- **验收**：  
  - [ ] 收藏列表可按年份/题材筛选  
  - [ ] 笔记绑定 target；取消收藏时默认保留笔记并提示  

### FR-08 站点导航提示

- **描述**：说明官网含 Mobile PhotoAwards / Film / Exhibitions；**首期仅 PhotoAwards 2025/2026**；评委需对照**中文区** Photo Awards。  
- **验收**：  
  - [ ] 不暗示已收录 Film/Exhibitions 全库  
  - [ ] 不暗示英文 Europe 视图一定有评委块

## 6. 信息架构 / 主要界面与用户流程

### 6.1 信息架构（IA）

```
赛影
├── 首页（届次入口：2026 / 2025）
├── 赛事详情
│   ├── 获奖作品列表（筛选：题材 / 奖项 / 优秀）
│   ├── 作品详情 → AI 入选解读卡 → 外链官网
│   └── 届次概览（可选 AI）
├── 评委
│   ├── 评委列表（按届次）
│   └── 评委详情 → AI 风格卡（原文 | 推断）
├── 我的
│   ├── 收藏
│   ├── 笔记
│   └── 截图引用
└── 关于 / 数据说明（范围、诚实性、locale 提示）
```

### 6.2 主要界面

| 界面 | 关键元素 |
|------|----------|
| 首页 | 两届卡片、一句话产品说明、「学习向推断」提示 |
| 作品列表 | 筛选条、作品卡、空态 |
| 作品详情 | 元数据、点赞标注、AI 卡入口、外链、收藏/笔记 |
| 评委列表/详情 | 届次标签、简介原文、风格推断卡 |
| 收藏/笔记 | 列表、编辑、筛选 |
| 关于 | 数据源 URL、范围、禁止项说明 |

### 6.3 核心用户流程（Remi）

1. 打开 App → 选 **2026** 或 **2025**  
2. 进入获奖列表 → 按题材或奖项筛选  
3. 打开一件作品 → 阅读元数据 → 打开 **AI 入选解读**  
4. （可选）跳转评委 → 读风格卡 → 对照练习建议  
5. 收藏 / 写笔记 / 保存截图引用  

成功路径定义：首次会话完成「打开一届 → 打开一件获奖作 → 读完 AI 入选卡 ≥ 1」。

## 10. 非功能需求

### 10.1 性能

- 作品列表首屏：常规网络下可感知流畅（具体预算工程自定并写入 SLA）  
- AI 不阻塞浏览；无缓存时先骨架后填充  

### 10.2 隐私与内容

- 仅公开页 + 用户笔记/收藏/截图引用  
- 不采集无关设备权限  
- AI 展示区固定生成说明，避免被误认为 vivo 官方评语  

### 10.3 合规与归属

- 标题、作者、奖项、评委名与简介为公开信息的引用整理  
- 详细大图以链回官网为主  

### 10.4 可用性

- 中文界面优先（对齐 Remi）  
- 关键路径不超过 3 次点击到达 AI 入选卡

## 11. 成功指标、Out of Scope 与风险

### 11.1 成功指标（目标向 KPI）

| 指标 | 目标 |
|------|------|
| 单作品理解 | 约 **3 分钟**读懂入选要点 |
| 核心路径 | 首次会话完成：一届 → 一作 → AI 卡 ≥ 1 |
| 学习沉淀 | 定向测试人均收藏或笔记 ≥ 1 |
| 诚实性抽检 | 无假评分/评语；推断均有本赛证据 |
| 数据覆盖 | 2025/2026 已采集获奖作入库 **100%**；评委 2026 五人 + 2025 Alex Webb 可展示且可追溯中文 Photo Awards |

### 11.2 Out of Scope（v1）

| 排除项 | 说明 |
|--------|------|
| 2025 以前届次 | 不含 2024 及更早 |
| 其他赛事品牌 | 非 VISION+ 一律不做 |
| 评委站外履历 / 站外作品集 | 不采集、不展示 |
| 代投稿 / 登录代操作 | 不做 |
| 批量原图图床 | 除非用户明确截图引用 |
| 伪造评语、分数、假官方结果 | 严禁 |
| Film / Exhibitions 完整库 | 仅导航说明 |
| 多赛事聚合、定时全自动抓取、深度美学精调 | 后续 |
| 支付、订阅商城、社交 Feed | 不做 |

### 11.3 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| Photo Awards locale 隐藏评委 | 评委库为空 | 强制中文区；失败告警 |
| 无官方评语 | 只能做学习向推断 | UI「非官方」+ evidence |
| DOM/URL 变更 | 映射失效 | 版本化解析 + 种子人工校对 |
| likes 被误读为分 | 产品误解 | 文案与字典统一 |
| 用户期望投稿 | 客诉 | FR 不做；关于页说明截止日 |
| 过度解读个人口味 | 误导 | 强制「推断」；禁站外补强 |
