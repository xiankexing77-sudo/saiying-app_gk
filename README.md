# 赛影

面向摄影新手的 **vivo VISION+ Mobile PhotoAwards** 学习助手，只收录 **2025** 与 **2026**。

可以按年份、题材、奖项浏览获奖作品，查看评委席位，阅读标明「推断」的风格卡和入选原因。它不是图床，不是投稿工具，也不是官方赛务后台。

## 本地运行

需要 Node.js 22+。

```bash
npm install
npm run dev
```

开发服务器默认在 [http://127.0.0.1:41731](http://127.0.0.1:41731)。

```bash
npm test
npm run lint
npm run build
```

## 数据范围与诚实性

- 只做 Mobile PhotoAwards 2025 / 2026。官网还有 Film、Exhibitions，本站没有收录。
- 作品字段来自官网获奖列表与作品详情（标题、作者展示名、题材、奖项、机型、点赞、分享、说明、`workId`）。缺字段显示「来源页暂无」。
- 点赞是读者互动，**不是评分**，也不拿来解释入选。
- 2025 公示评语按官网页面署名放在「官网原文」。没有署名的不指认评委。2026 接口里没有评语文本，不补写。
- 评委简介只使用中文区 Photo Awards 页上能核对到的文字。黎晓亮的完整简介原文未抓到，故留空。不展示站外履历，也不做「曾在其他赛事担任评委」栏目。
- 评委信息请对照**简体中文 / 中国区**。英文 Europe 视图可能看不到评委区块。
- 入选解读和风格卡由 `src/lib/analysis/generate.ts` 的本地模板生成，落成 `AnalysisResult`（含 `evidence_json`）。页面可以重新生成，结果缓存在浏览器本地。模板禁止伪造评语、分数，以及「某位评委单独决定某作」。
- 不下载、不托管获奖原图。详情链回官网 `workId`。截图引用只保存网址和你填写的本地文件名。
- 收藏、笔记、截图引用存在浏览器 `localStorage`。取消收藏时笔记默认保留。

2026 届投稿截止的公开信息是 **2026-06-26**（已结束）。赛影不能代投稿。

## 目录

- `src/app` 页面：首页、届次、作品、入选解读、评委、我的、关于
- `src/lib` 数据查询与推断模板
- `data/seed.json` 种子档案
- `scripts/build-seed.mjs` 从本地抓取快照重写种子（需要 `/tmp` 中的接口缓存，日常运行不必执行）
